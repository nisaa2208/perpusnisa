Deskripsi
Aplikasi ini merupakan sistem informasi berbasis web yang dirancang untuk membantu pengelolaan data secara terstruktur dan efisien. Sistem ini digunakan untuk mengelola data seperti produk, pengguna, transaksi, dan laporan secara digital sehingga proses bisnis menjadi lebih cepat, akurat, dan mudah diakses.
Aplikasi dibangun menggunakan teknologi web seperti PHP dan MySQL, serta dapat dijalankan secara lokal menggunakan web server seperti XAMPP.
Fitur Utama
Login User
Sistem menyediakan fitur autentikasi menggunakan username dan password untuk mengamankan akses pengguna.
Manajemen Data (CRUD)
Pengguna dapat melakukan:
Menambahkan data
Melihat data
Mengedit data
Menghapus data
Transaksi
Sistem mendukung pengelolaan transaksi dengan fitur:
Input transaksi
Perhitungan total otomatis
Penyimpanan data transaksi
Laporan
Sistem menyediakan laporan data:
Harian
Mingguan
Bulanan
(Opsional) export ke PDF
Database Terintegrasi
Data disimpan menggunakan MySQL sehingga lebih terstruktur dan mudah dikelola.
Cara Menjalankan Web
1. Persiapan
Pastikan perangkat telah terpasang:
XAMPP atau software web server sejenis
Web browser (Google Chrome, Microsoft Edge, atau lainnya)
2. Menjalankan Server
Buka aplikasi XAMPP
Aktifkan Apache dan MySQL
3. Import Database
Buka browser dan akses:
http://localhost/phpmyadmin
Buat database baru sesuai dengan nama yang digunakan pada project
Import file database (.sql) yang tersedia di dalam folder project
5. Login Sistem (Jika tersedia)
Gunakan akun yang telah dibuat di database, misalnya:
Username: admin
Password: admin
